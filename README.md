# Babado Eleitoral

A ressaca do 2º turno de 2026 contada em tom de fofoca: os fatos vêm das reportagens linkadas em cada nota, e os pitacos de humor ficam separados e marcados como opinião.

Site: https://matheus-bittencourt.github.io/babado-eleitoral/

Os dados ficam em `site/data.json` e são atualizados duas vezes por dia. Cada push no `main` valida o arquivo e republica o site.
